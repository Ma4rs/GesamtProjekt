# OnlineCasino – Schulprojekt

## Projektbeschreibung

Dieses Projekt ist ein Onlinecasino, das im Rahmen eines Schulprojektes entwickelt wurde. Ziel ist es, verschiedene Casinospiele digital anzubieten und dabei Programmierkenntnisse sowie Teamarbeit zu vertiefen.

**Enthaltene Spiele:**
- **Blackjack**
- **Roulette**
- **Triple Guess**
- **(Viertes Spiel in Planung)**

## Verzeichnisstruktur

- `Games/` – Implementierungen der Casinospiele
- `Webservice/` – Backend-Komponenten und Schnittstellen (.NET)
- `Picture/` – Grafiken und Ressourcen

## Installation & Start

1. Repository klonen:
   ```bash
   git clone https://gl.edvschule-plattling.de/bfs2023ik/202425trfiaeb2/onlinecasino.git
   ```
2. In das Verzeichnis (aktuell `develop`) wechseln (falls nicht automatisch):
   ```bash
   cd GesamtProjekt
   ```
3. Abhängigkeiten installieren:
   ```bash
   npm i
   ```
4. In das Webservice-Verzeichnis wechseln und Backend starten:
   ```bash
   cd Webservice
   dotnet run
   ```
5. Zurück ins Hauptverzeichnis und den Live-Server starten (z. B. mit VS Code „Go Live“):
   - Stelle sicher, dass du im richtigen Verzeichnis bist.
   - „Go Live“ (meist unten rechts in VS Code) starten.

## Nutzung

- Nach dem Start ist das Casino über den Browser erreichbar.
- Anmleden bzw. Regestrieren und anschließen kann man Spiele auswählen und Credits aufladen
- Wähle ein Spiel aus dem Menü, um loszulegen.
